# LexicalSpace v30

- **Practice:** Select English → Vietnamese or Vietnamese → English above the card. In reverse mode, press Enter to check the English answer. A wrong answer is saved as Again and queued for another try. Reveal and audio count as hints until the answer has been submitted. The existing session limit, progress and retry queue remain in effect.
- **Gestures and keys:** Drag the card grip left for Again, up-left for Hard, up-right for Good or right for Easy. The colored badge shows the action before release. Flip before grading in the standard mode. The icon bar has keyboard-accessible controls; Space flips, 1–4 grade and R replays audio.
- **Library:** Use the left toolbar for audio, flip, edit and delete. Fronts show word, IPA, translation, synonyms and collocations. Backs show examples and usage notes. Word cards keep the same dimensions on either face.
- **Entry:** Enter a target and select **Quick Fill / Điền nhanh**. Free Dictionary can fill IPA and POS without a Groq key. To generate a Vietnamese meaning, estimated CEFR level and context, enter your key under **Quick Fill settings**. The default model is `llama-3.3-70b-versatile`; Quick Fill tries `openai/gpt-oss-120b` if Groq reports the first model is unavailable. Review the form before saving. The key stays in the tab by default. **Remember the key in this browser** stores it for this local profile; uncheck it to clear the saved key. No key is shipped or added to library records.
- **AI Library Generator:** Enter one word or phrase per line, copy the prompt, run it in your preferred AI tool and paste its JSON array back. The copied prompt specifies the full schema. Every row and the requested word list are checked before any write. New words start with interval 0, repetition 0 and ease 2.5. Updates to existing words preserve review history and require checking the overwrite option. All rows and their sync operations are written together.
- **Loading:** The typewriter starts immediately. The app opens when local storage is ready, without waiting for cloud sync or for the typewriter to finish.

Serve this directory from HTTPS or localhost for service worker and Clipboard API support. Manual entry and local study do not require Groq. Cloud and AI integrations are mocked in automated tests; run `npm ci` and `npm test` to check locally.
